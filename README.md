### `>` universal-resilience-toolkit

Um pacote único e flexível para lidar com **retries, rate limits, circuit breakers e persistência de estado**, sem enfiar dependências obrigatórias no seu projeto.

```ts
// exponential backoff · token bucket · circuit breaker com half-open state
// estado em SQLite ou Redis, com fallback silencioso para memória do processo
// pronto para plugar OpenTelemetry e rastrear cada tentativa
```

> Roda em **Node.js · Bun · Deno · Cloudflare Workers · Vercel Edge**
> Publicado no GitHub Packages como `@1a8jkf/universal-resilience-toolkit`

[![Repo](https://img.shields.io/badge/ver_repositório-0D1117?style=flat-square&logo=github&logoColor=00FF9C)](https://github.com/1a8jkf/universal-resilience-toolkit)

<br/>

### `>` DevFlux

Uma **IDE mobile de verdade** para quem não tem acesso a um PC. Roda **Alpine Linux nativo** com shell totalmente funcional, permitindo subir aplicações Node.js direto do Android — com gerenciamento de memória para não destruir o aparelho.

> Conexões SSH, integração com Supabase, AWS e outros bancos, Sync-Code e backups de projeto no estilo Git.
> **Em breve na Play Store.**

<br/>
